# Joye Life v3.0.12

## Guided Career Coach

- Replaced the form-heavy Career experience with a guided first-use interview.
- Generates a personalized three-phase path: Build the skills, Prove the skills, Make the move.
- Identifies likely skill and proof gaps from the user's target, barrier, and current context.
- Highlights one clear next action and lets the user add it directly to the Weekly tab.
- Adds a Career Evidence library for wins, projects, praise, certifications, metrics, and resume bullets.
- Keeps advanced custom actions available without making them the default experience.
