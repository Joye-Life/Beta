# Joye Life brand assets

The brand assets are stored in `public/brand`.

- `joye-mark-dark.png` — primary square app/logo mark
- `joye-mark-transparent.png` — transparent mark for dark or decorative surfaces
- `favicon.ico` and `favicon.png` — browser icons
- `apple-touch-icon.png` — iOS home-screen icon
- `icon-192.png` and `icon-512.png` — PWA icons
- `joye-og-image.png` — social sharing preview
- `joye-logo-artwork.jpg` — cropped supplied artwork for future brand use

## Core palette

- Night: `#070916`
- Purple: `#9B3CFF`
- Violet: `#6D34F2`
- Blue: `#4055F8`
- Cyan: `#18C5EF`
- Mint: `#55E4C9`

The shared gradient is defined by the `.brand-gradient` class in `app/globals.css`.
