# Joye Life v3.0.8

- Uses the signed-in member's browser-local time for the Today greeting.
- Adds visible saving states to Profile, Career, Goals, Weekly, Money, Paycheck Plan, and Feedback forms.
- Shows clear success or failure messages after database writes.
- Stops silently ignoring Supabase write failures.
- Fixes the Weekly Plan build/save workflow feedback.
- Adds clearer confirmation for income, bills, debt, paycheck plans, and item removal.

No new Supabase migration is required for this release.
